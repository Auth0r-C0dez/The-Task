# START HERE — Agentic Dating (ZIP handoff)

This package runs on any computer with Node.js 18+ (no node_modules included — install once).

## 1) Install Node.js LTS
https://nodejs.org

## 2) Two terminals inside this unzipped folder

### Terminal 1 — API
cd backend
npm install
npm run seed
npm run dev

### Terminal 2 — Website
cd frontend
npm install
npm run dev

## 3) Open
http://localhost:3000

Then click **Load demo & open rankings**.
